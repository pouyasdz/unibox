## 🌟 نمای کلی

**UniBox** یه ابزار کاملاً کلاینت‌ساید برای دانشجوهاست. همه چیز در یه فایل HTML، بدون سرور، بدون دیتابیس، بدون نصب.

```
یه فایل HTML  →  باز کن در مرورگر  →  همه ابزارها آماده‌ست ✅
```

## 📲 بخش ۵ — کارت اشتراک‌گذاری

یه ویژگی وایرال برای تشویق مطالعه و به اشتراک گذاشتن پیشرفت:

- 🎴 **پیش‌نمایش کارت** با گرادیان زیبا
- 📱 **پیش‌نمایش موبایل** — دقیقاً همون متنی که کپی میشه در قالب حباب پیام
- 📌 **پیش‌نمایش بیو پروفایل** — برای استفاده در اینستاگرام، تلگرام و...
- انتخاب موضوع مطالعه از ۱۰ رشته مختلف
- دو دکمه جداگانه: **کپی متن پیام** + **کپی بیو**

```
📚 علی امروز ۳ ساعت مطالعه کرد!
📖 موضوع: 💻 برنامه‌نویسی
🔥 با UniBox مطالعه هوشمند رو تجربه کن

#UniBox #مطالعه_هوشمند
```

## ⚡ Focus Mode

یه محیط مطالعه تمام‌صفحه بدون حواس‌پرتی:

- تایمر پومودورو بزرگ با انیمیشن حلقه‌ای
- دکمه‌های صدای محیطی (باران 🌧 / کافه ☕ / جنگل 🌲)
- پس‌زمینه تاریک کامل
- خروج با دکمه `Escape`
